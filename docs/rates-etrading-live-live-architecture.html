Rates e-trading desktop — production architecture

A live/live distribution platform across two data centers, projecting the E-Trading system of record onto the OpenFin trading desktop. Both sites serve traders every day, each carries the full desk, and every component below the shared cache can be rebuilt from it. Select any component — including the team boundary — for its design rationale.

Live/live, not active/standbyBoth data centers serve real users daily — failover is a routinely exercised path, never an untested hope.
Each DC carries the full deskEvery site is sized for 100% of users, so losing one is a capacity non-event.
Failover in seconds, client-drivenDesktops reconnect to the surviving site automatically and resynchronize a clean snapshot.
One source of truthCoherence remains the system of record; the AMPS layers are rebuildable projections of it.
One-way data flowState flows down from the source of truth; order entry crosses back through an explicit, versioned service contract — never through the shared cache.
Determinism over coordinationThe two DC projections are equivalent by construction, so nothing has to synchronize them — and clients can switch sites seamlessly.
Disposable projectionsAMPS is a rebuildable view of Coherence, never a second system of record. Recovery is always re-projection, not reconciliation.
Ownership with clean contractsE-Trading to Coherence, Rubicon below it. The cache schema is the versioned contract; accountability is answerable in seconds.
